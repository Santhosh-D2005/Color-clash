# Branding — Color Clash

The game was built against a brief whose supplied key art carried another
company's registered wordmark. That was recorded from the first build as
**RF-014** and flagged as blocking for public distribution. This document is
what replaced it.

`npm run audit:brand` fails the build if the previous mark reappears in any
shippable file, and it runs in CI and in `npm run verify`.

---

## The identity

**Color Clash.** The mark is a four-shard prism: four coloured triangles
meeting at a point, with a gold core. Every other asset is built from that one
shape rule — shards, chevrons, and a 12-degree shear that runs through the set.

|                  |                                                     |
| ---------------- | --------------------------------------------------- |
| Name             | Color Clash                                         |
| Package id       | `com.geeksforgames.colorclash`                      |
| npm scope        | `@colorclash/*`                                     |
| Declaration call | **CLASH!** — shouted when you play down to one card |

### Palette

Defined once, in the `BRAND` block of `tools/gen-brand.ts`, and mirrored by the
CSS custom properties at the top of `apps/client/src/styles/app.css` and by
`COLOR_HEX` in `packages/game-content/src/colors.ts`. The four shard colours
are deliberately off the primary hues.

| Role    | Hex       |
| ------- | --------- |
| Shard 1 | `#e2483f` |
| Shard 2 | `#f2b134` |
| Shard 3 | `#2f9e5e` |
| Shard 4 | `#2f7fd4` |
| Ink     | `#070f20` |
| Gold    | `#f0b840` |

### Mode names

Gameplay is untouched. Only the names changed.

| Was               | Now               | Engine id  |
| ----------------- | ----------------- | ---------- |
| Classic           | **Classic Clash** | `CLASSIC`  |
| Flip              | **Flipstorm**     | `FLIP`     |
| Show 'Em No Mercy | **Mayhem**        | `MAYHEM`   |
| All Wild          | **Wild Rush**     | `ALL_WILD` |
| Flex              | **Freestyle**     | `FLEX`     |

Three engine ids are unchanged because they are plain descriptions of what the
mode does rather than anyone's brand — a deck that flips, cards that are all
wild. The fourth was a product's actual phrase, so it changed with the name.

## The artwork

Every image in the game is generated by `tools/gen-brand.ts`, which is not a
build step over source images — **it is the source**. Each asset is authored
there as SVG built from primitives and rasterised with sharp. Nothing is
traced, sampled or derived from any other product, and the entire visual
identity can be regenerated from scratch:

```bash
npm run brand      # redraw every image, then rebuild both asset registries
```

That produces 41 game images, 4 app icons, a 1024px store icon and two splash
screens. Sizes match the previous set exactly, so no layout shifted.

**Card faces carry no images at all.** They are drawn in CSS: one element, one
face colour, one shard motif on the identity's diagonal, and a text glyph. The
shard replaced a tilted highlight ellipse that was the other product's most
recognisable card feature.

There are no audio files in this repository. Every cue — card, draw, penalty,
declaration, elimination, victory — is generated from oscillators when it plays,
which is why the sound design costs zero bytes in the offline build and the APK,
and why there is nothing to license.

**Before adding any external asset**, record it in the table above with its
source, licence, whether commercial use is permitted, and any attribution the
licence requires. An asset that cannot be described that way does not go in.

## What is still checked by hand

The audit script greps text. Two things it cannot do:

1. **Look at an image.** If someone replaces a generated PNG with a downloaded
   one, the audit will pass. The defence is that the images are generated, so
   a replaced file shows up as an unexplained binary in review.
2. **Judge similarity.** "Not the same mark" is a legal question, not a regex.
   The design here is deliberately far from the original: a different name, a
   different shape language, a different card face, and a colour palette
   shifted off the primaries.
